# DocSpaceIA — Contexto do Projeto

## Visão Geral
Portal de documentação interativa sobre astronomia, astrofísica e exploração espacial. O projeto começou como uma migração de um site multi-páginas vanilla (DocSpaceV2) para React + TypeScript + Vite, e evoluiu para uma plataforma completa com 10 artigos científicos, quiz, linha do tempo espacial, comparador de planetas, glossário interativo, modo leitura, busca global, tema claro/escuro, e suporte a Android via Capacitor.

## Tech Stack
- **React 19** + **TypeScript 5.8**
- **Vite 7** (bundler)
- **Tailwind CSS v4** (estilização)
- **React Router DOM v7** (SPA routing)
- **Capacitor 8** (Android build)

## Rotas
| Rota | Página | Descrição |
|------|--------|-----------|
| `/` | Home | Landing com estrelas animadas + cards de navegação |
| `/documentation` | Documentation | Tabs + busca + grids + modal + comparador de planetas |
| `/articles` | Articles | Artigos com sumário, glossário, modo leitura, aleatório |
| `/timeline` | Timeline | Linha do tempo espacial interativa (22 eventos) |
| `/quiz` | Quiz | Quiz astronômico com 10 perguntas aleatórias |
| `/search` | Search | Busca global em artigos, planetas, luas e estrelas |
| `/about` | About | Texto institucional |
| `/contact` | Contact | Perfis Instagram dos criadores |
| `*` | 404 | Página personalizada "Você se perdeu no espaço?" |

## Estrutura de Dados

### types.ts
```ts
CelestialBody { name, description, image }
PlanetInfo extends CelestialBody { type, diameter, distanceFromSun, dayLength, yearLength, gravity, temperature, moonsCount, color }
MoonInfo extends CelestialBody { planet, diameter }
StarInfo extends CelestialBody { spectralType, distance, magnitude, temperature }
```

### articles.ts / featuredArticles.ts
```ts
DocArticle { id, title, icon, blocks: ArticleBlock[] }
ArticleBlock { type: 'heading' | 'text' | 'image' | 'video', content?, src?, alt?, caption?, videoTitle? }
```

### glossary.ts
```ts
GlossaryEntry { term, definition } — 25 termos astronômicos
```

### quiz.ts
```ts
QuizQuestion { question, options: string[4], correct: index } — 20 perguntas
```

### timeline.ts
```ts
TimelineEvent { year, title, description, category: 'exploração'|'descoberta'|'telescópio'|'missão' } — 22 eventos
```

## Design Conventions
- **Cores**: bg-gray-900 (fundo), bg-gray-800 (cards), blue-600 (acento)
- **Glass**: backdrop-blur-md + bg-gray-900/80 para headers
- **Cards**: bg-gray-800/50 backdrop-blur-sm border-gray-700/50 rounded-xl hover:-translate-y-1
- **Tipografia**: text-gray-200 (títulos), text-gray-300 (corpo), text-gray-500 (secundário)
- **Tema claro**: CSS custom properties que sobrescrevem classes Tailwind via `.light`
- **Animações**: fadeIn nas transições de página, estrelas pulsantes na Home
- **Responsivo**: mobile-first, grid adaptativo

## Funcionalidades

### Tema Claro/Escuro
- Detecta `prefers-color-scheme` do sistema
- Salva preferência no localStorage
- Botão sol/lua no Navbar

### Glossário Interativo
- Termos científicos destacados nos artigos
- Clique abre popup com definição
- 25 termos cadastrados

### Modo Leitura
- Aumenta fontes e espaçamento
- Remove distrações visuais
- Toggle no topo dos artigos

### Comparador de Planetas
- Seleciona dois planetas
- Compara 7 propriedades lado a lado
- Acessível via botão "Comparar" na Documentação

### Quiz Astronômico
- 10 perguntas aleatórias de um pool de 20
- Feedback visual (verde/vermelho)
- Placar percentual no final

### Linha do Tempo Espacial
- 22 eventos históricos
- 4 categorias com cores distintas
- Layout alternado em desktop

### Busca Global
- Pesquisa em artigos, planetas, luas e estrelas
- Rota `/search?q=`
- Input expansível no Navbar

### Página 404
- Tema espacial com estrelas animadas
- Mensagem "Você se perdeu no espaço?"

## Histórico de Mudanças
1. **Setup inicial**: React + TS + Vite + Tailwind, migrado do DocSpaceV2
2. **Sidebar → Navbar**: Substituída sidebar por navbar no topo
3. **Simulador 3D**: Adicionado com React Three Fiber (removido depois)
4. **Documentação enriquecida**: Dados científicos, tabs, busca, modal
5. **Artigos reformados**: Conteúdo em data files, busca, visão de leitura
6. **Visual renovado**: Home, About e Contact com gradiente + estrelas
7. **10 artigos científicos**: Cosmologia, exoplanetas, nebulosas, sistema solar, estrelas
8. **Timeline, Quiz, 404**: Páginas interativas
9. **Glossário + Modo Leitura**: Termos destacados e leitura confortável
10. **Comparador de Planetas**: Side-by-side de propriedades
11. **Busca Global**: Pesquisa em todo o conteúdo
12. **Tema Claro/Escuro**: Detecção do sistema + toggle manual
13. **Transições**: fadeIn entre páginas
14. **BackToTop**: Botão flutuante com scroll suave
15. **App Android**: Capacitor + APK gerado
16. **Logo personalizada**: SVG com planeta + anéis
